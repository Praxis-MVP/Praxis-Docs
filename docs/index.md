# Welcome to Praxis Docs

Welcome to the documentation! This site is built with Markdoc and deployed on GitHub Pages.

## Getting Started

Browse the documentation using the sidebar navigation. Here's what you'll find:

- **Getting Started** - Quick start guides and installation instructions
- **Guides** - Step-by-step tutorials and how-tos
- **Reference** - Detailed technical reference

## Writing Documentation

Documentation files are written in Markdown and stored in the `docs` folder. Simply create or edit `.md` files and push to GitHub - the site will automatically rebuild.

### Frontmatter

Each markdown file can include frontmatter at the top:

```yaml
---
title: Page Title
description: A brief description
order: 1
---
```

- `title` - The page title (shown in navigation and browser tab)
- `description` - Meta description for SEO
- `order` - Controls the order in the navigation (lower numbers appear first)
